# 발표용 그림

**저장소가 이미 판정한 것을 발표 자료에 넣을 형태로 다시 말한 것이다.** 새로 잰
것이 하나도 없다 — 값은 전부 아래 표가 가리키는 자리에서 왔다.

## 구성

```
critical-sections-coverage.svg   임계 구역 여섯 × 무엇이 덮나 — 빈칸 포함
strategy-comparison.svg          전략 다섯 × 같은 사건이 어디에 나타나나
m3-oversell-by-contention.svg    초과 확정 × 경합도 — 1차 측정의 정합성 결론
m3-p95-by-contention.svg         p95 × 경합도 + 잡음 폭 — 성능으로는 못 가른다
second-campaign.svg              2차 측정 두 캠페인 — 규모·판정·결과
```

**한 장씩 떼어 써도 되고, 위 순서가 곧 이야기 순서다** — 무엇을 지켜야 하나 →
어떻게 지켰나 → 그래서 무엇이 나왔나 → 그것으로 전략을 가를 수 있나 → 무엇을
더 밟았나.

## 규율 — 그림이 문서보다 세게 말하지 않게 한다

**세 가지를 지켰다.**

### 순위를 읽는 그림을 만들지 않는다

**p95를 막대로 나란히 세우면 비율 0.78~1.79가 차이처럼 보인다.** 7.7.1과
`m3-conclusion.md` 2.5가 *"세션 간 변동이 전략 간 차이보다 크다"*로 판정한
값이다. 그래서 **잡음을 주장하지 않고 그려 넣었다** — 맨 아랫줄의 다섯 점이
같은 조건을 다섯 세션에서 잰 것이고, 음영이 그 폭이다. **읽는 사람이 눈으로
비교한다.**

### `none`은 색이 아니라 위치로 가른다

**대조군이자 유일하게 검수 기준을 위반하는 쪽**이라 맨 윗줄에 놓고 배경을
깔았다. 다섯에 제각각 색을 주면 그 구분이 사라진다.

### 빈칸을 지우지 않는다

**임계 구역 지도에 CS-2·CS-3이 「열려 있다」로 남아 있다.** 2절이 *"이
프로젝트에서 가장 자주 터진다"*고 지목한 구역인데 **부하로 한 번도 안
밀어봤다.** 덮인 것만 그리면 그림이 문서보다 세게 말하게 된다.

## `results/` 문서에 싣지 않는다

**`m3-conclusion.md`에는 이미 같은 값이 표로 있다**(1절 · 2.1 · 2.5). 그림을 그
옆에 두면 **같은 사실을 두 곳에서 지키게 되고**, `erd.md` 4절이 *"같은 사실을 두
곳에서 지키면 어긋난다"*로 금지한 형태다. **표는 고치기 쉽고 SVG는 조용히 안
고쳐진다.**

**그림의 성격이 제출물과 같다.** `submissions/README.md`가 수업 제출물을 두고
*"판단을 새로 만드는 것이 아니라 이미 있는 판단을 수업이 요구한 형식으로 다시
말한 것"*이라 적었고, 이 그림도 그렇다. **정본 옆이 아니라 따로 둔다.**

> **한때 `results/figures/` 에 있었다.** 측정 결과에서 나온 둘뿐이라 그 아래
> 두었는데, **임계 구역 지도와 전략 비교는 측정 결과가 아니다.** 한 종류를 두
> 폴더로 나누는 것이 더 나쁘다고 보고 `docs/figures/` 하나로 모았다.

> **다시 볼 조건 — 60회를 다시 재면.** 그때는 뒤의 셋이 낡는다. 다만
> `concurrency-spec.md` 7.3이 하네스 한계를 *"재측정으로 해소하지 않는다"*로,
> `m3-conclusion.md` 3.5가 성능 축을 *"하지 않는다"*로 판정했으므로 **60회는
> 닫힌 데이터다.** 그 판정이 뒤집히면 이 줄이 이 그림들을 가리킨다.

## 그리는 수단 — 손으로 쓴 SVG, 생성기를 두지 않는다

**의존성이 없다.** `tools/render-md.mjs`가 `npx marked`를 쓰지 않은 것과 같은
근거다 — *"사전 준비가 필요한 발표 도구는 그 준비를 잊었을 때 실패한다"*(`#147`).

**생성기를 커밋하지 않는 이유는 따로 있다.** 스크립트와 SVG를 둘 다 두면 **두
벌이 생기고 한 벌만 낡는다** — `#196`이 `DEMO_TABS`에서 겪은 형태다. 위 조건대로
데이터가 닫혀 있으므로 **결과물 하나만 남긴다.**

## 발표 자료에 넣는 법

**`.pptx`는 저장소 밖이다**(`submissions/README.md`). SVG를 그대로 삽입하면 되고,
PowerPoint가 SVG를 못 받으면 브라우저에서 열어 PNG로 저장한다.

**배경을 흰색(`#fcfcfb`)으로 박아 두었다** — 슬라이드 배경이 무엇이든 글자가
읽히고, GitHub 다크 모드에서도 같은 그림이 나온다.

## 색

| 쓰임 | 값 |
|---|---|
| 저경합 · 고경합 · 극단 | `#2a78d6` · `#eb6834` · `#1baf7a` |
| 덮였다 · 열려 있다 · 해당 없음 | `#1baf7a` · `#eb6834` · `#7a7973` |
| `none` (대조군·위반) | `#e34948` — 행 배경 `#fbf1f1` |
| 같은 조건 재측정 | `#7a7973` |

**색맹 판별 가능성을 확인하고 골랐다.** 세 색이 모든 쌍에서 CVD ΔE 9.2 이상
(6~8이 하한선), 정상 시야 ΔE 24.0 이상(15가 하한선)이다.

**상태를 색으로만 말하지 않는다.** 임계 구역 지도의 「덮였다 / 열려 있다 / 해당
없음」은 **글자로 적혀 있고** 색은 거들 뿐이다. `#1baf7a`가 배경 대비 2.74:1로
3:1에 못 미치는 것도 같은 이유로 문제가 되지 않는다 — 점마다 숫자를, 상태마다
낱말을 직접 달았다.
