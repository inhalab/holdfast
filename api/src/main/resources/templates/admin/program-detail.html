회차 등록

회차를 만들면 좌석재고와 할당량 행이 함께 생성됩니다. 좌석재고를 미리 만드는 것이 좌석 단위 락의 전제입니다.

사용자 풀 크기는 미리 만들어 둘 user_session_quota 행 수입니다. 회원 기능이 없어 "누구의 행을 만들지"가 정해지지 않으므로 사용자 1..N을 만듭니다 — 이 행이 없으면 홀드가 실패합니다.
